PRAKASH M — PORTFOLIO WEBSITE (UPDATED)

FILES
- index.html: website content and layout
- style.css: responsive design and styling
- script.js: mobile navigation and current footer year
- Prakash_M_Resume.pdf: resume PDF downloaded from the resume you supplied

HOW TO VIEW
1. Extract this ZIP folder.
2. Keep all files together in the same folder.
3. Double-click index.html to open the portfolio in your browser.
4. Use the "Download Resume" button to download the included PDF.

PUBLISHING
Upload all four website files together to your web host. The resume PDF must remain beside index.html so the download links work.

BEFORE PUBLISHING
- Verify experience dates and scores against your original resume.
- The Rasi LED end date in the source resume is ambiguous.
- Add real GitHub repository/live-demo URLs to projects only after confirming them.
- Make sure you are comfortable publishing your phone number, email and resume publicly.
